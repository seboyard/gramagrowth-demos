# Plantilla de demo o entrega

Esta carpeta se duplica por prospecto o cliente. No editarla con datos reales sin crear primero una copia.

## Adaptación mínima

1. Cambiar los valores de `config.js` usando sólo información pública o aprobada.
2. Reemplazar los textos genéricos por el problema y la oferta del negocio.
3. Configurar un canal de contacto real antes de presentar la demo.
4. Probar móvil, escritorio, navegación, WhatsApp y formulario.
5. Rotular como `Muestra conceptual` mientras no sea una entrega aprobada.

No agregar testimonios, precios, acreditaciones, fotos o resultados que no estén verificados.
